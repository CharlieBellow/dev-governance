
# Skills Específicas do Projeto: To-Do API

## 1. `db-seed` (Exemplo)
- **O que faz:** Popula o banco de dados local com dados fictícios para testes de integração.
- **Como rodar:** `pnpm prisma db seed`

## 2. `run-unit` (Exemplo)
- **O que faz:** Executa exclusivamente os testes unitários do domínio ignorando a infraestrutura.
- **Como rodar:** `pnpm vitest run src/domain`
